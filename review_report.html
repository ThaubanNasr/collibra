Purpose

“What

The data download capability from the SAP Analytics Cloud (SAC) Data Analyzer is required to support the Event Management process. The downloaded data is used to review, analyze, and compare process performance statistics over time. It enables business users to perform detailed offline analysis of the underlying data beyond the standard dashboard visualizations, supporting continuous monitoring and evaluation of Event Management process performance.

The downloaded data consists of aggregated process performance metrics, including process KPIs, PPIs, and alert-related information generated through the Event Management reporting. The data is used exclusively for internal business purposes and does not introduce any new data processing activities beyond those already supported by the SAC reporting solution.

Target audience

The data is consumed by Global Cloud Operation (GCO) Event Management Process Owners, Operational Teams, and Global Cloud Operation (GCO) Management stakeholders responsible for monitoring process performance, driving operational improvements, and supporting governance activities.

Data Download

Process

As a consumer of the SAP Analytics Cloud (SAC) Data Analyzer, authorized users can export the underlying report data to supported file formats (such as CSV or Microsoft Excel) for further offline analysis and documentation. The exported data contains aggregated Event Management process metrics, including KPIs, PPIs, and alert information used for process performance monitoring.

Purpose

The data download functionality is required to ensure transparency, traceability, and informed decision-making within the Event Management process. Specifically, the downloaded data enables authorized users to:

  • perform detailed data validation and quality checks on reported process metrics;
  • analyze and compare historical process performance and trends;
  • prepare internal reports for management and operational stakeholders;
  • support internal decision-making and process steering activities;
  • identify process alerts and derive corrective actions for continuous process improvement; and
  • document analyses and decisions supporting governance and operational excellence.

The downloaded data is used exclusively for internal business purposes. The download functionality does not constitute a new data processing activity but provides a technically necessary means of using data that is already lawfully processed within SAP Analytics Cloud to support analysis, validation, reporting, and continuous process improvement.
