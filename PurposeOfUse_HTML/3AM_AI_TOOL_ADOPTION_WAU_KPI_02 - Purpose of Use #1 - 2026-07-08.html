3AM_AI_TOOL_ADOPTION_WAU_KPI_02 - Purpose of Use #1 - 2026-07-08

Purpose

SAP is going All-in-on-AI and is rapidly evaluating and rolling out AI tools across the entire product development lifecycle. This derived data product provides a trusted and harmonized view of AI adoption and output across AI coding assistants. This derived data product aggregates data from multiple sources (GitHub Copilot, Claude Code, Cline, and organizational unit data) and transforms the data into aggregated metrics enabling data-driven decisions for SAP’s investments into AI tools.

 

Data Privacy Shield

 

The dashboard which consumes this derived data product displays only aggregated metrics. Data of individual users is not displayed in the dashboard. 

 

We have implemented a Data Privacy Shield in the Executive AI Insights dashboard which ensures that no data is shown on the dashboard if the result set of any drill-down is <8 users. This is in accordance with data privacy requirements, and previous discussions with the SAP Group Works Council.
Beschreibung

SAP setzt voll auf KI und evaluiert und implementiert KI-Tools schnell über den gesamten Produktentwicklungszyklus hinweg. Dieses abgeleitete Datenprodukt bietet eine vertrauenswürdige und harmonisierte Übersicht über die KI-Nutzung und -Ausgabe von KI-Coding-Assistenten. Dieses abgeleitete Datenprodukt aggregiert Daten aus mehreren Quellen (GitHub Copilot, Claude Code, Cline sowie Organisationseinheitsdaten) und transformiert diese in aggregierte Kennzahlen, die datengestützte Entscheidungen für SAPs Investitionen in KI-Tools ermöglichen.

Data Privacy Shield

Das Dashboard, das dieses abgeleitete Datenprodukt verwendet, zeigt ausschließlich aggregierte Kennzahlen an. Daten einzelner Benutzer werden im Dashboard nicht angezeigt.

Wir haben einen Data Privacy Shield im Executive AI Insights Dashboard implementiert, der sicherstellt, dass keine Daten im Dashboard angezeigt werden, wenn die Ergebnismenge eines beliebigen Drill-downs <8 Benutzer umfasst. Dies entspricht den Datenschutzanforderungen und den vorherigen Absprachen mit dem SAP Group Works Council.
Authorization
  • The output port consumption is controlled via Access Request Management (ARM) roles (Consumption role and Enabler role). 
  • This Data Product implements a Single Values Data Access Control (DAC) mechanism based on organizational units (0ORGUNIT). Access is granted at organizational level by assigning users to specific L1 - L6 organizational units or equivalent structures.
