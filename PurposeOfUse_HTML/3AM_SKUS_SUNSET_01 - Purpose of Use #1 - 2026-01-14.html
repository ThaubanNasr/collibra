3AM_SKUS_SUNSET_01 - Purpose of Use #1 - 2026-01-14

Purpose

This Analytical Model provides the License Materials (SKUs) which are either part of a Sunset Project, or which are Cloud SKUs off Pricelist (Status A7, A8 or A9) and still have customer contracts.

If assigned to a Sunset Project, the Project ID and Status will be provided.

This will be exposed in the Portfolio Sunset Dashboard, and will provide a view where the users can check if a certain License Material (SKU) is already part of a Sunset Project, or if it has been taken off the Pricelist without involvement of the Sunset Team.

Access to the SAC Dashboard will be provided with a Role which will only be provided to Users from Product Management or in other roles responsible for Managing Sunset Projects.
Beschreibung Dieses Analytische Modell liefert die License Materials (SKUs), die entweder Teil eines Sunset Project sind oder Cloud SKUs off Pricelist (Status A7, A8 oder A9) sind und noch Kundenverträge haben. Wenn sie einem Sunset Project zugeordnet sind, werden die Project ID und der Status angegeben. Dies wird im Portfolio Sunset Dashboard dargestellt und bietet eine Ansicht, in der die Benutzer überprüfen können, ob ein bestimmtes License Material (SKU) bereits Teil eines Sunset Project ist oder ob es ohne Beteiligung des Sunset Team vom Pricelist genommen wurde. Access to the SAC Dashboard wird mit einer Rolle bereitgestellt, die nur Benutzern aus dem Product Management oder in anderen Rollen, die für die Verwaltung von Sunset Projects verantwortlich sind, zugewiesen wird.
Authorization Private Access, via SAC Model, Dashboard End Users will have to request role PORTFOLIO_SUNSET_R via ARM. EndUsers will be Product Managers, Executive Leadership, Engineering Operations Teams, Operations Managers, Sunset Coaches, Sunset Leads, Pricing Experts, Cloud Renewal Centers

EndUsers werden Product Managers, Executive Leadership, Engineering Operations Teams, Operations Managers, Sunset Coaches, Sunset Leads, Pricing Experts, Cloud Renewal Centers sein.
