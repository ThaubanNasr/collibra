3AM_COMMUNICATED_AVAIL_PE_STEERING_DASHBOARD_01 - Purpose of Use #1 - 2026-01-28

Purpose

This derived data product contains Service Provider Cockpit Communicated Availability along the Solution Area and Sub-Solution Area. It calculates the SLA violations against customer SLAs.


Purpose

This data product can be utilized to compute SLA breaches for tenants.

Communicated Availability is reported in the quarterly SVB meetings on Solution Area Level.  

For the SVB briefing the analysis of SLA breached are analysed on a quarterly basis.


Target Group

Selected responsible employees for the SVB KPI preparation for the P&E board area


Data Download

Purpose

As the responsible for the SVB KPI preparation for the P&E board area we need to deliver the charts in a predefined layout using Think Cell or Microsoft excel charts.
The 3 P&E board area KPIs represent only a sub-set of the overall SVB management report. The SVB management report is a collection of KPIs from all board areas and facilitates the preparation of the SVB pre-read document.
To ensure consistency, for all KPIs a common format has been defined and needs to be followed by all board areas.  This dedicated visualization format can not identically be created as a chart in the SAC story.

 

Process
The access to this dedicated SVB preparation SAC dashboard is limited to only very selected colleagues in the P&E Business Steering Team which are involved in the SVB preparation.
The responsible for the SVB KPI preparation in the P&E Business Steering Team can export the underlying data to external file formats to generate the required charts.
Please see: https://help.sap.com/docs/SAP_ANALYTICS_CLOUD/00f68c2e08b941f081002fd3691d86a7/ff5f1e052b5e400da990dad8408604da.html
Data download is only possible along the Solution Area Hierarchy. There is no direct personal data involved – the report does not contain any direct employee name or user-ID information.
Beschreibung

Dieses abgeleitete Datenprodukt enthält Service Provider Cockpit Communicated Availability entlang der Solution Area und Sub-Solution Area. Es berechnet die SLA-Verletzungen gegenüber den Kunden-SLAs.
Zweck Dieses Datenprodukt kann genutzt werden, um SLA-Verstöße für Mieter zu berechnen. Communicated Availability wird in den vierteljährlichen SVB-Meetings auf Solution Area Ebene berichtet.
Für das SVB-Briefing werden die Analysen der SLA-Verstöße vierteljährlich ausgewertet.

Zielgruppe

Ausgewählte verantwortliche Mitarbeiter für die SVB KPI-Vorbereitung für den P&E Board-Bereich

Daten-Download

Zweck

Als Verantwortliche für die SVB KPI-Vorbereitung für den P&E Board-Bereich müssen die Diagramme in einem vordefinierten Layout mit Think Cell oder Microsoft excel-Diagrammen geliefert werden. Die 3 P&E Board-Bereich KPIs stellen nur einen Teil des gesamten SVB-Managementberichts dar. Der SVB-Managementbericht ist eine Sammlung von KPIs aus allen Board-Bereichen und erleichtert die Vorbereitung des SVB-Vorlesedokuments. Um Konsistenz zu gewährleisten, wurde für alle KPIs ein gemeinsames Format definiert, das von allen Board-Bereichen eingehalten werden muss. Dieses spezielle Visualisierungsformat kann nicht identisch als Diagramm in der SAC-Story erstellt werden.

Prozess
Der Zugang zu diesem speziellen SVB-Vorbereitungs-SAC-Dashboard ist nur sehr ausgewählten Kollegen im P&E Business Steering Team vorbehalten, die an der SVB-Vorbereitung beteiligt sind. Die Verantwortlichen für die SVB KPI-Vorbereitung im P&E Business Steering Team können die zugrunde liegenden Daten in externe Dateiformate exportieren, um die erforderlichen Diagramme zu erstellen. Bitte siehe: https://help.sap.com/docs/SAP_ANALYTICS_CLOUD/00f68c2e08b941f081002fd3691d86a7/ff5f1e052b5e400da990dad8408604da.html
Der Daten-Download ist nur entlang der Solution Area-Hierarchie möglich. Es sind keine direkten personenbezogenen Daten beteiligt – der Bericht enthält keine direkten Mitarbeiter-Namen oder Benutzer-ID-Informationen.
