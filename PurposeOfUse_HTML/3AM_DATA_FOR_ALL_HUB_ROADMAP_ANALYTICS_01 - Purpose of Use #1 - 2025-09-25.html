3AM_DATA_FOR_ALL_HUB_ROADMAP_ANALYTICS_01 - Purpose of Use #1 - 2025-09-25

Purpose

This Analytic Model contains current information about Data Products and their relations to Output Ports and Input Ports.

Distinct Count of Data Products, related Output Ports and Input Ports are enriched by restricted measures based on status or other attributes. All entities have rich master data entities.

The data will be updated every 24h from Data for All Hub 5:00AM CET

  • Dashboard Builder or Analyzer should use this Output Port for providing analytics on Data Products.
  • Data Product Owner, Engineer, Domain Owner, Governance Manager and Operations Teams can use this Output Port for analyzing the current status of their live Data Products as well as their roadmap.
  • Works Council, their Subject Matter Experts and Working Committee can use this Output Port for analyzing Output Ports within their responsibility
Beschreibung

Dieses Analytische Modell enthält aktuelle Informationen über Data Products und deren Beziehungen zu Output Ports und Input Ports.

Die Anzahl von Data Products, zugehörigen Output Ports und Input Ports werden durch eingeschränkte Kennzahlen aufgrund von Status oder anderen Attributen angereichert. Alle Entitäten verfügen über umfangreiche Stammdaten-Entitäten. Die Daten werden alle 24 Stunden vom Data for All Hub um 5:00 Uhr CET aktualisiert.

  • Dashboard Builder oder Analyzer sollten diesen Output Port verwenden, um Analysen über Data Products bereitzustellen.
  • Data Product Owner, Engineer, Domain Owner, Governance Manager und Operations Teams können diesen Output Port nutzen, um den aktuellen Status ihrer live Data Products sowie ihre Roadmap zu analysieren.
  • Works Council, ihre Subject Matter Experts und Working Committee können diesen Output Port nutzen, um Output Ports innerhalb ihrer Verantwortung zu analysieren.
