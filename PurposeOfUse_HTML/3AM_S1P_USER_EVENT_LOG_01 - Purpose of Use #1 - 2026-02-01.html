3AM_S1P_USER_EVENT_LOG_01 - Purpose of Use #1 - 2026-02-01

Purpose This Output Port provides a specialized User Activity Monitoring dataset, essential for ensuring that SAC S1P remains SOX compliant. It enables auditors to track specific user behaviors, administrative changes, and transport-related actions across SAP Datasphere and Jira. To maintain a legally required audit trail for security-sensitive operations, full user identification (SAP User ID) is mandatory. For this reason, anonymization is not feasible, as the audit must confirm the identity of individuals performing critical system modifications. Access is restricted via the SOX_AUDIT_R role and governed by the 'need-to-know' principle.
Beschreibung Dieser Output Port stellt einen spezialisierten User Activity Monitoring-Datensatz bereit, der für die Sicherstellung der SOX-Konformität von SAC S1P unerlässlich ist. Er ermöglicht es Prüfern, spezifische Benutzerverhalten, administrative Änderungen und transportbezogene Aktionen in SAP Datasphere und Jira nachzuverfolgen. Um eine gesetzlich vorgeschriebene Prüfspur für sicherheitsrelevante Vorgänge zu gewährleisten, ist eine vollständige Benutzeridentifikation (SAP User ID) zwingend erforderlich. Aus diesem Grund ist eine Anonymisierung nicht möglich, da die Prüfung die Identität der Personen bestätigen muss, die kritische Systemänderungen vornehmen. Der Zugriff ist über die SOX_AUDIT_R-Rolle eingeschränkt und wird nach dem Prinzip der „Notwendigkeit der Kenntnis“ geregelt.
Authorization

Authorization Model: Access is restricted via the SOX_AUDIT_R Data Enabler Role. Users must submit an access request through the ARM (Access Request Management) system.

Approval Workflow: Every request must be approved by the Data Product Owner (or Space Owner). For German employees, access is further governed by the approved Purpose of Use document and Works Council co-determination rights.

Data Visibility & Granularity: Data is displayed at the granular level of individual User IDs and Event IDs. This provides auditors with a detailed "Audit Trail" to monitor specific user activities across SAC S1P
Security Mechanism: The model utilizes All/Nothing Authorization. Row-level security is enforced via Data Access Control (DAC); users without the authorized role will not see any data records, ensuring "need-to-know" access compliance.
Authorization (German)

Berechtigungsmodell: Der Zugriff ist strikt auf die Data Enabler Rolle SOX_AUDIT_R beschränkt. Benutzer müssen einen Zugriffsantrag über das ARM-System (Access Request Management) stellen.

Genehmigungs-Workflow: Jeder Antrag muss manuell durch den Data Product Owner (Space Owner) geprüft und freigegeben werden. Für deutsche Mitarbeiter unterliegt der Zugriff zusätzlich diesem genehmigten Purpose of Use Dokument und den Mitbestimmungsrechten des Betriebsrats.

Datensichtbarkeit und Granularität: Die Daten werden auf granularer Ebene einzelner Benutzer-IDs und Ereignis-IDs angezeigt. Dies ermöglicht Auditoren einen detaillierten „Audit Trail“ zur Überwachung spezifischer Benutzeraktivitäten und Verhaltensweisen in SAC S1P.

Sicherheitsmechanismus: Das Modell nutzt die All/Nothing-Autorisierung. Die Sicherheit auf Zeilenebene wird über Data Access Control (DAC) erzwungen; Benutzer ohne die autorisierte Rolle sehen keinerlei Datensätze, was die strikte Einhaltung des „Need-to-know“-Prinzips gewährleistet.
