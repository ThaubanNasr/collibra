3AM_MCC_GEM_01 - Purpose of Use #1 - 2026-03-04

Purpose

The purpose of this DP is to cover reporting and analytic needs of SAP MCC Global Escalation Management (GEM) process. It helps to track process performance and quality metrics like volume of incoming requests, volume of processed escalations, processing durations, etc. SAP MCC business can look for trends and patterns related to customers and their regions, products and their deployment types, business impact, involved BUs and many more. Primary audience of this DP are GEM global and regional process owners as well as members of SAP MCC senior leadership team.

This analytic model provides measures important for GEM business along with actual values of all fields (dimensions) maintained within the process flow.

  • # Global Escalations - count of GEM escalation records independently from their state (so, this measure can be used to count escalation requests and GEM cases)
  • # Top Issues - count of Top Issue (TI) records (childs) associated with GEM escalation records (parents)
  • # Unique Products - count of unique PPMS products associated with GEM escalation records
  • Avg. # GE Initial Cases - number of customer Cases initially assigned to each Global Escalation Request; AVG aggregation is applied
  • Avg. # GE Products - number of PPMS products associated with each Global Escalation; AVG aggregation is applied
  • Avg. # GE Reassignments - number of Assignment Group changes related to each GEM escalation record; AVG aggregation is applied
  • Avg. # GE Top Issues - number of Top Issues associated with each Global Escalation; AVG aggregation is applied
  • Avg. # GE Execution Time (Days) - time between Approval Set and Closure (or current) date of a GEM escalation record, in days; AVG aggregation is applied
  • Avg. # GE Request Qualification Time (Hours) - time between Creation and Approval Set (or current) date of a GEM escalation record, in hours; AVG aggregation is applied
  • Avg. # GE Total Processing Time (Days) - time between Creation and Closure (or current) date of a GEM escalation record, in days; AVG aggregation is applied
  • Avg. # SLA GE Execution Time (Days) - execution time for a GEM escalation record captured by ServiceNow SLA framework, in days; AVG aggregation is applied
  • Avg. # SLA GE Total Processing Time (Days) - total processing time for a GEM escalation record captured by ServiceNow SLA framework, in days; AVG aggregation
  • Avg. # SLA GE Request Qualification Time (Hours) - GE request qualification time captured by ServiceNow SLA framework, in hours; AVG aggregation is applied
  • Avg. # SLA GE Initial Response Time (Hours) - GE initial response time captured by ServiceNow SLA framework, in hours; AVG aggregation is applied
Beschreibung

Dieses Datenmodell dient der Abdeckung der Berichts- und Analyseanforderungen des SAP MCC Global Escalation Management (GEM)-Prozesses. Es unterstützt die Verfolgung von Prozessleistungs- und Qualitätskennzahlen wie dem Volumen eingehender Anfragen, dem Volumen bearbeiteter Eskalationen, den Bearbeitungsdauern usw. SAP MCC Business können Trends und Muster in Bezug auf Kunden und deren Regionen, Produkte und deren Bereitstellungstypen, Geschäftsauswirkungen, beteiligte Geschäftseinheiten und vieles mehr erkennen. Die primäre Zielgruppe dieses Datenmodells sind globale und regionale GEM-Prozessverantwortliche sowie Mitglieder des SAP MCC-Führungsteams.

Dieses Analysemodell liefert wichtige Kennzahlen für das GEM-Geschäft sowie die Istwerte aller im Prozessablauf verwalteten Felder (Dimensionen).

# Globale Eskalationen – Anzahl der GEM-Eskalationsdatensätze unabhängig von ihrem Status (diese Kennzahl kann also zur Zählung von Eskalationsanfragen und GEM-Fällen verwendet werden)

# Top-Probleme – Anzahl der Top-Problem-Datensätze (untergeordnete Datensätze), die mit GEM-Eskalationsdatensätzen (übergeordnete Datensätze) verknüpft sind

# Eindeutige Produkte – Anzahl der eindeutigen PPMS-Produkte, die mit GEM-Eskalationsdatensätzen verknüpft sind # GE-Erstfälle – Anzahl der Kundenfälle, die ursprünglich jeder globalen Eskalationsanfrage zugewiesen wurden; Durchschnittsberechnung wird angewendet

Durchschnitt # GE-Produkte – Anzahl der PPMS-Produkte, die jeder globalen Eskalation zugeordnet sind; Durchschnittsberechnung wird angewendet

Durchschnitt # GE-Neuzuweisungen – Anzahl der Änderungen der Zuweisungsgruppe im Zusammenhang mit jedem GEM-Eskalationsdatensatz; Durchschnittsberechnung wird angewendet

Durchschnitt # GE-Top-Probleme – Anzahl der Top-Probleme, die jeder globalen Eskalation zugeordnet sind; Durchschnittsberechnung wird angewendet

Durchschnitt # GE-Ausführungszeit (Tage) – Zeit zwischen Genehmigungsdatum und Abschlussdatum (oder aktuellem Datum) eines GEM-Eskalationsdatensatzes in Tagen; Durchschnittsberechnung wird angewendet

Durchschnitt # GE-Qualifizierungszeit (Stunden) – Zeit zwischen Erstellungsdatum und Genehmigungsdatum (oder aktuellem Datum) eines GEM-Eskalationsdatensatzes in Stunden; Durchschnittsberechnung wird angewendet # Gesamtbearbeitungszeit für GEM-Eskalationen (Tage) – Zeitspanne zwischen Erstellung und Abschlussdatum (bzw. aktuellem Datum) eines GEM-Eskalationsdatensatzes in Tagen; Durchschnittsberechnung angewendet

Durchschnittliche Ausführungszeit für SLA-Eskalationen (Tage) – Ausführungszeit eines GEM-Eskalationsdatensatzes, erfasst durch das ServiceNow SLA-Framework, in Tagen; Durchschnittsberechnung angewendet

Durchschnittliche Gesamtbearbeitungszeit für SLA-Eskalationen (Tage) – Gesamtbearbeitungszeit eines GEM-Eskalationsdatensatzes, erfasst durch das ServiceNow SLA-Framework, in Tagen; Durchschnittsberechnung angewendet

Durchschnittliche Qualifizierungszeit für SLA-Eskalationen (Stunden) – Qualifizierungszeit einer GE-Anfrage, erfasst durch das ServiceNow SLA-Framework, in Stunden; Durchschnittsberechnung angewendet

Durchschnittliche erste Antwortzeit für SLA-Eskalationen (Stunden) – erste Antwortzeit einer GE-Anfrage, erfasst durch das ServiceNow SLA-Framework, in Stunden; Durchschnittsberechnung angewendet
