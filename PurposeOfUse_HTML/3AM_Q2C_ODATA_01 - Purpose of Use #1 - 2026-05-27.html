3AM_Q2C_ODATA_01 - Purpose of Use #1 - 2026-05-27

Purpose

This output port originates from the Cloud Reporting dataset found here: https://reporting.ondemand.com/sap/crp/cdo?type=CRP_ODAT&list=50&period_type=dp

OData Statistics contain functional usage data of OData APIs of Quote-To-Cash. With this output port, Product Managers and Engineers are able to do informed decisions about their APIs.

This dataset contains no personal data, that allows to identify a specific person. The Account IDs within this dataset are referring to the CRM Account ID, that identifies certain SAP customers (non persons).

Dieser Ausgabe-Port stammt aus dem Cloud Reporting Datensatz, der hier zu finden ist: https://reporting.ondemand.com/sap/crp/cdo?type=CRP_ODAT&list=50&period_type=dp
