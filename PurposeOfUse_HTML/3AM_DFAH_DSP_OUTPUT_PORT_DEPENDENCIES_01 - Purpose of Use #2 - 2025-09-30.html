3AM_DFAH_DSP_OUTPUT_PORT_DEPENDENCIES_01 - Purpose of Use #2 - 2025-09-30

Purpose

This Analytic Model contains current information about Output Ports in Status Build Hosted on SAP Datasphere. Main KPI is the Difference between Planned Publish Date of Consuming and Consumed Output Port and derived categories: >90 days, between 90 and 0 days, consumed output port is planned after the consuming.

The data will be updated every 24h from Data for All Hub 5:00AM CET

  • Dashboard Builder or Analyzer should use this Output Port for providing analytics on Data Products.
  • Data Product Owner, Data Domain Owner should use this Output Port for analyzing their Datasphere Roadmap Dependency Issues.
  • Works Council, their Subject Matter Experts and Working Committee can use this Output Port for deriving their workload with Output Ports within their responsibility

Data Model

  • Every pair of providing and consuming output port is listed with its time in days between their planned publish dates
  • Primary Key: "Providing and consumed Output Port ID"
  • Filter on both Output Ports:
    • Status: Build
    • Planned Publish Date: Exists
    • Host System: CPIT - SAP Datasphere
  • Input Port is only to connect the Data Products, but it is not necessary in the model
Beschreibung

Dieses Analytische Modell enthält aktuelle Informationen über Output Ports im Status Build, gehostet auf SAP Datasphere. Der Haupt-KPI ist die Differenz zwischen dem geplanten Veröffentlichungsdatum des bereitstellenden und des empfangenden Output Ports und abgeleitete Kategorien: >90 Tage, zwischen 90 und 0 Tagen, empfangender Output Port ist nach dem bereitstellenden geplant.

Die Daten werden alle 24 Stunden vom Data for All Hub um 5:00 Uhr CET aktualisiert.

  • Dashboard Builder oder Analyzer sollten diesen Output Port verwenden, um Analysen zu Data Products bereitzustellen.
  • Data Product Owner, Data Domain Owner sollten diesen Output Port verwenden, um ihre Datasphere Roadmap Dependency Issues zu analysieren.
  • Works Council, ihre Subject Matter Experts und Working Committee können diesen Output Port verwenden, um ihre Arbeitsbelastung mit Output Ports innerhalb ihrer Verantwortung abzuleiten.
Authorization

Request the ARM Consumer Request BDP role. Any Data Citizen will be approved due to no direct personal identifiable information in the data set. The role will enable access to the whole data set.
