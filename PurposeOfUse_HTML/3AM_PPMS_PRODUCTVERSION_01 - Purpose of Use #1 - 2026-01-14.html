3AM_PPMS_PRODUCTVERSION_01 - Purpose of Use #1 - 2026-01-14

Purpose

This Analytical Model provides the PPMS Product Versions linked to a PPMS Product, and helps the User Groups to identify all Product Versions belonging to a PPMS Product, with the relevant information like Maintenance End Dates.

This will be exposed in the Portfolio Sunset Dashboard, which provides along Sunset Information an overview of all PPMS Software Products.

In the Dashboard this view will be shown along with other information of a PPMS Product, like the assigned SKUs and Component Versions to a PPMS Product.

The Sunset Coaches, Sunset Leads, Product Managers will get with the PPMS view all relevant information to a PPMS Product, e.g. if this Product is in an ongoing Sunset Project.

A Sunset Coach, Product Manager, Operations expert, ec. Get a quick overview if a PPMS Product is in Sunset, and for ongoing or new sunsets which Product Versions need to be retired, and which component Versions and SKUs are potentially affected by a Product Sunset.

Access to the SAC Dashboard will be provided with a Role which will only be provided to Users from Product Management or in other roles responsible for Managing Sunset Projects.
Beschreibung Dieses Analytical Model stellt die PPMS Product Versions bereit, die mit einem PPMS Product verknüpft sind, und hilft den User Groups, alle Product Versions zu identifizieren, die zu einem PPMS Product gehören, mit den relevanten Informationen wie Maintenance End Dates. Dies wird im Portfolio Sunset Dashboard dargestellt, das neben Sunset Information einen Überblick über alle PPMS Software Products bietet. Im Dashboard wird diese Ansicht zusammen mit anderen Informationen eines PPMS Product angezeigt, wie den zugewiesenen SKUs und Component Versions zu einem PPMS Product. Die Sunset Coaches, Sunset Leads, Product Managers erhalten mit der PPMS Ansicht alle relevanten Informationen zu einem PPMS Product, z.B. ob dieses Product sich in einem laufenden Sunset Project befindet. Ein Sunset Coach, Product Manager, Operations-Experte erhält einen schnellen Überblick, ob ein PPMS Product sich im Sunset befindet und für laufende oder neue Sunsets welche Product Versions eingestellt werden müssen und welche Component Versions und SKUs potenziell von einem Product Sunset betroffen sind. Der Zugriff auf das SAC Dashboard wird mit einer Rolle bereitgestellt, die nur Users aus dem Product Management oder in anderen Rollen, die für das Management von Sunset Projects verantwortlich sind, zugewiesen wird.
