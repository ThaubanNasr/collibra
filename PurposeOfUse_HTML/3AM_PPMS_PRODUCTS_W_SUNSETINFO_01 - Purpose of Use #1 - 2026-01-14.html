3AM_PPMS_PRODUCTS_W_SUNSETINFO_01 - Purpose of Use #1 - 2026-01-14

Purpose

This Analytical Model provides the PPMS Products and related Sunset information where available.

This will be exposed in the Portfolio Sunset Dashboard, which provides along Sunset Information an overview of all PPMS Software Products.

In the Dashboard this view will be shown along with other information of a PPMS Product, like the assigned SKUs and Component Versions to a PPMS Product.

The Sunset Coaches, Sunset Leads, Product Managers will get with this report all relevant information to a PPMS Product, e.g. if this Product is in an ongoing Sunset Project, the Sunset Project ID and the Phase the Project is in.

A Sunset Coach, Product Manager, Operations expert, ec. Get a quick overview if a PPMS Product is in Sunset, and for ongoing or new sunsets which Product Versions need to be retired, and which component Versions and SKUs are potentially affected by a Product Sunset.

Access to the SAC Dashboard will be provided with a Role which will only be provided to Users from Product Management or in other roles responsible for Managing Sunset Projects.
Beschreibung

Dieses analytische Modell liefert die PPMS Products und zugehörigen Sunset-Informationen, wo verfügbar.

Dies wird im Portfolio Sunset Dashboard dargestellt, das neben Sunset-Informationen einen Überblick über alle PPMS Software Products bietet.

Im Dashboard wird diese Ansicht zusammen mit anderen Informationen zu einem PPMS Product angezeigt, wie den zugewiesenen SKUs und Component Versions zu einem PPMS Product.

Die Sunset Coaches, Sunset Leads, Product Managers erhalten mit diesem Bericht alle relevanten Informationen zu einem PPMS Product, z. B. ob dieses Produkt in einem laufenden Sunset Project ist, die Sunset Project ID und die Phase, in der sich das Projekt befindet.

Ein Sunset Coach, Product Manager, Operations-Experte usw. erhält einen schnellen Überblick, ob ein PPMS Product im Sunset ist, und für laufende oder neue Sunsets, welche Product Versions eingestellt werden müssen und welche Component Versions und SKUs potenziell von einem Product Sunset betroffen sind.

Zugriff auf das SAC Dashboard wird mit einer Rolle bereitgestellt, die nur Benutzern aus dem Product Management oder in anderen Rollen, die für die Verwaltung von Sunset Projects verantwortlich sind, zugewiesen wird.
