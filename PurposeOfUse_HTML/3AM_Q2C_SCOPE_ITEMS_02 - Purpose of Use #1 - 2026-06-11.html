Purpose

Scope items in SAP Cloud ERP Public are preconfigured, testable building blocks that bundle end-to-end processes, configuration settings, sample data, and test scripts for a specific business scenario. They accelerate fit-to-standard implementations by providing ready-to-activate process variants (e.g., customer returns), which you can adopt as-is or extend—ensuring consistent documentation, testing, and lifecycle management.

This dataset originates from the HAUM solution features DP: https://sap.collibra.com/asset/01937771-d3dc-70ea-851d-581ef08636d7

Product Managers and Engineers in Cloud ERP Public can use scope items to understand how many customers are using their processes.

Scope Items contain only feature usage and contain no personal identifiable information. "Account ID" refers to the CRM Account IDs.
Beschreibung

Scope Items in SAP Cloud ERP Public sind vorkonfigurierte, testbare Bausteine, die End-to-End-Prozesse, Konfigurationseinstellungen, Beispieldaten und Testskripte für ein bestimmtes Geschäftsszenario bündeln. Sie beschleunigen Fit-to-Standard-Implementierungen, indem sie sofort aktivierbare Prozessvarianten bereitstellen (z. B. Kundenretouren), die Sie unverändert übernehmen oder erweitern können – und so eine konsistente Dokumentation, Tests und Lebenszyklusverwaltung gewährleisten.

Dieser Datensatz stammt aus den HAUM Solution Features DP: https://sap.collibra.com/asset/01937771-d3dc-70ea-851d-581ef08636d7

Produktmanager und Ingenieure in Cloud ERP Public können Scope Items verwenden, um zu verstehen, wie viele Kunden ihre Prozesse nutzen.

Scope Items enthalten ausschließlich Informationen zur Funktionsnutzung und keine personenbezogenen Daten. „Account ID" bezieht sich auf die CRM Account IDs.
