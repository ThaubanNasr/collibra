3AM_PPMS_ALL_OBJECTS_01 - Purpose of Use #1 - 2026-01-14

Purpose

This Analytical Model provides the PPMS Objects of Type PPMS Product, PPMS Component Version and PPMS Product Version.

This will be exposed in the Portfolio Sunset Dashboard, and will provide a view where the Users can search for a PPMS Object independent of the Object Type. This view will help to identify a PPMS Object and provide the information which Object type (Product, Product Version or Component Version) it is. It helps to find an Object if only the ID or not the exact name is available.

Access to the SAC Dashboard will be provided with a Role which will only be provided to Users from Product Management or in other roles responsible for Managing Sunset Projects.
Beschreibung

Dieses analytische Modell stellt die PPMS Objects vom Typ PPMS Product, PPMS Component Version und PPMS Product Version bereit.

Dies wird im Portfolio Sunset Dashboard angezeigt und bietet eine Ansicht, in der die Users nach einem PPMS Object unabhängig vom Objekttyp suchen können. Diese Ansicht hilft dabei, ein PPMS Object zu identifizieren und liefert Informationen darüber, welcher Objekttyp (Product, Product Version oder Component Version) es ist. Es hilft, ein Objekt zu finden, wenn nur die ID oder nicht der genaue Name verfügbar ist.

Zugriff auf das SAC Dashboard wird mit einer Rolle bereitgestellt, die nur Users aus dem Product Management oder in anderen Rollen, die für die Verwaltung von Sunset Projects verantwortlich sind, erhalten.
