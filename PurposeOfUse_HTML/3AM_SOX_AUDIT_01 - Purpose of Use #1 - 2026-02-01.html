3AM_SOX_AUDIT_01 - Purpose of Use #1 - 2026-02-01

Purpose This Output Port provides a consolidated audit dataset integrating SAC access logs with JIRA transport activities. It is a critical component for maintaining SAC S1P SOX compliance, enabling auditors and compliance teams to perform end-to-end analysis of access, system changes, and approval workflows. To ensure a legally required and reliable audit trail, full user identification (SAP User ID) is mandatory. Consequently, anonymization is not feasible, as auditors must be able to verify the specific individuals responsible for critical production events and transport approvals. Access is strictly governed via the SOX_AUDIT_R role and restricted to authorized personnel only.
Beschreibung Dieser Output Port stellt einen konsolidierten Audit-Datensatz bereit, der SAC-Zugriffsprotokolle mit JIRA-Transportaktivitäten kombiniert. Er ist eine kritische Komponente für die Aufrechterhaltung der SOX-Compliance von SAC S1P und ermöglicht Audit- und Compliance-Teams eine lückenlose End-to-End-Analyse von Zugriffen, Systemänderungen und Genehmigungs-Workflows. Um einen gesetzlich vorgeschriebenen und zuverlässigen Audit-Trail zu gewährleisten, ist die vollständige Identifizierung der Benutzer (SAP User-ID) zwingend erforderlich. Folglich ist eine Anonymisierung nicht realisierbar, da Auditoren verifizieren müssen, welche spezifischen Personen für kritische Produktionsereignisse und Transportgenehmigungen verantwortlich waren. Der Zugriff wird streng über die Rolle SOX_AUDIT_R kontrolliert und ist auf autorisiertes Personal beschränkt.
Authorization

Access Requirements: To access the data, users must request the ARM role SOX_AUDIT_R (Data Enabler Role).

Approval Process: Requests for this role are approved by the Data Product Owner (Space Owner).

Data Granularity & Visibility: The data is provided at a granular transaction level (Event Log). Consumers will see detailed records of actions performed by users (e.g., Jira tickets, SAC events) aggregated by User ID and Event ID.

Anonymization & Security: No anonymization is applied to authorized users as User IDs are required for audit purposes. Row-level security is implemented using a Data Access Control (DAC) with an "All or Nothing" approach. Users without the assigned ARM role will see no data.
Authorization (German)

Zugriffsanforderungen: Um auf die Daten zuzugreifen, müssen Benutzer die ARM-Rolle SOX_AUDIT_R (Data Enabler Role) anfordern.

Genehmigungsprozess: Anträge für diese Rolle werden vom Data Product Owner (Space Owner) genehmigt.

Daten-Granularität & Sichtbarkeit: Die Daten werden auf granularer Transaktionsebene (Event Log) bereitgestellt. Nutzer sehen detaillierte Aufzeichnungen von Aktionen, die von Benutzern durchgeführt wurden (z. B. Jira-Tickets, SAC-Ereignisse), aggregiert nach User-ID und Event-ID.

Anonymisierung & Sicherheit: Für autorisierte Benutzer wird keine Anonymisierung angewendet, da User-IDs pro Prüfzwecke zwingend erforderlich sind. Die Sicherheit auf Zeilenebene wird mittels Data Access Control (DAC) mit einem „Alles-oder-Nichts“-Ansatz umgesetzt. Benutzer ohne die zugewiesene ARM-Rolle sehen keinerlei Daten.
